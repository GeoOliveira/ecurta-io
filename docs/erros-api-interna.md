# Erros da API interna

Formato: `{"error":{"code":"...","message":"...","retryable":false},"meta":{"requestId":"..."}}`.

Códigos: `INTEGRATION_DISABLED`, `UNAUTHORIZED`, `INVALID_SIGNATURE`, `REQUEST_EXPIRED`, `INVALID_REQUEST_ID`, `INVALID_CONTENT_TYPE`, `PAYLOAD_TOO_LARGE`, `VALIDATION_ERROR`, `INVALID_PHONE`, `INVALID_EXPIRATION`, `RATE_LIMIT_EXCEEDED`, `IDEMPOTENCY_CONFLICT`, `LINK_NOT_FOUND`, `INTEGRATION_LINK_ACCESS_DENIED`, `CREATION_DISABLED`, `SERVICE_UNAVAILABLE` e `INTERNAL_ERROR`. Nunca são retornados stack, SQL ou dados pessoais.
