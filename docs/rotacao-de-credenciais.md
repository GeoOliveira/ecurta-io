# Rotação de credenciais

1. Gere nova API key e HMAC fortes.
2. Configure nos ambientes Preview dos dois sistemas.
3. Valide assinatura, criação, replay e consulta.
4. Configure produção ainda desativada.
5. Atualize a Alcance IA, valide e habilite ambiente e banco.
6. Revogue os valores anteriores e audite a rotação.

A primeira versão aceita um par; uma janela `current/previous` fica como evolução futura.
